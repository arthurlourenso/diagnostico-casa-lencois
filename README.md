## 🎯 Sobre o Projeto

Este repositório contém a aplicação web interativa em formato de slides executivos (proporção 16:9), sem dependências externas de frameworks pesados, garantindo carregamento instantâneo e total fidelidade visual.

### Destaques e Funcionalidades
- **Navegação Intuitiva:**
  - Teclas de seta: `←` (anterior) e `→` (próximo)
  - Botões de navegação e barra de progresso no rodapé
  - Suporte a cliques na tela
- **Design Institucional:** Identidade visual e paleta oficial da Virtus Desenvolvimento.
- **Gráficos e Indicadores:** Gráficos vetoriais em SVG nativo de alta definição.
- **Responsividade e Proporção Fixa:** Renderização fluida ajustada para telas Full HD e projetores.
