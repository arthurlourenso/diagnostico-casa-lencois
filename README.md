# Diagnóstico Financeiro — Casa Lençóis

Apresentação interativa dos slides do Diagnóstico Financeiro da Casa Lençóis, desenvolvida para a **Virtus Desenvolvimento**.

## Visualização Online
A apresentação está disponível no arquivo `index.html`. Ao ativar o GitHub Pages nas configurações deste repositório, ela poderá ser visualizada diretamente no navegador.

## Características
- Slides 16:9 autossuficientes em HTML/CSS/JS (sem dependências externas).
- Navegação por teclado (setas ← / →) e por clique.
- Paleta institucional da Virtus com gráficos vetoriais nativos em SVG.
